# Dataset instructions

No images are included. Create `data/chest_xray/` with `train/`, `val/`, and `test/` directories, each containing one subfolder per class (for example `COVID`, `NORMAL`, `PNEUMONIA`).

Before using a dataset, verify its provenance and current terms of use. Do not commit restricted or patient-identifiable images.
